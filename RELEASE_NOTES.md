## NewTube+ 1.0.1

### Coming from 1.0? Reinstall once
1.0 was a test build, signed with a one-off key, so 1.0.1 can't install over it. Uninstall 1.0, then install 1.0.1 (your settings and sign-in start fresh). From 1.0.1 on, updates come straight from this repo in the app: Settings → About → Check for updates, or the dot on the You tab. If 1.0 offers an update by itself, ignore it: 1.0 still checks the original NewTube.

### Install
Download the APK for your phone: **arm64-v8a** fits almost every modern phone; **universal** works on any. Allow "Install unknown apps" when Android asks. NewTube+ installs next to the original NewTube.

### What's new
- **Feed autoplay settings:** Settings → Playback → Feed autoplay. Turn it on or off, and play only on Wi-Fi (on by default).
- **Settings opens with a spinner** instead of a blank page while it loads.
- **Thumbnails no longer flash when switching tabs.**
- **No more sharp patches in the frosted bottom bar** while a preview plays under it.
- **Ambient mode no longer pulses** on a still picture.
- **Playlists tab shows two columns**, and the You tab no longer shows video placeholders.
